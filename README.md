# payment-ledger-core-go

本地支付账本核心：用**纯内存存储**模拟支付受理、复式记账、批次结算与对账全过程，
不依赖任何外部支付服务或网络接口。

## 能力概览

| 能力 | 说明 |
|------|------|
| 支付受理与幂等 | 幂等键 + 请求内容摘要；重复提交不重复扣款；同键不同内容明确拒绝（`IDEM_CONFLICT`）；失败也幂等且原因可区分 |
| 资金划转与复式记账 | 借贷必须相等；单笔/整批"先校验后提交"原子生效；并发下余额不为负、无丢失更新 |
| 批次结算与手续费 | 待结算交易按批次转已结算并按币种扣收手续费；整批原子；批次/交易重复结算被拒绝 |
| 对账 | 识别单边缺失（本地有/外部有）、金额不符、重复记录；金额不符自动生成调整交易；同批重放不重复调整 |

## 目录结构

```
internal/
  apperr/         业务错误码（失败原因可区分的唯一来源）
  domain/         账户、交易、分录、幂等记录、对账差异等领域模型
  storage/        内存存储（单把互斥锁 + 多 map）
  ledger/         复式记账核心：账户、Post、Atomic 临界区、结算状态流转
  payment/        支付受理与幂等处理
  settlement/     批次结算与手续费
  reconciliation/ 对账差异识别与自动调整
  e2etest/        端到端正常路径回归
cmd/demo/         本地可运行的全流程演示
docs/             记账规则、幂等与结算/对账语义、验证方法
```

## 快速体验

```bash
go run ./cmd/demo
go test ./... -v          # 全量单测（日志含幂等键/交易号与判定依据）
go test -race ./...       # 竞态检测
```

详细规则见 [docs/ACCOUNTING.md](docs/ACCOUNTING.md)。
